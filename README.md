# CRUD Operation App (React)

This is a simple CRUD (Create, Read, Update, Delete) application built using React.js.

---

## 🚀 Features

- Add new users
- View users list
- Edit existing users
- Delete users
- Simple and clean UI

---

## 🛠️ Tech Stack

- React.js (useState Hook)
- JavaScript (ES6)
- HTML/CSS (inline styling)
